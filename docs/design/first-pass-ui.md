# First-pass UI contract

## Core path
Campus Home → choose/create task → Start Focus → Focus Mode → Wrap-up → TIL → History/Stats.

## Four primary visual states
1. Campus Home
2. Start Focus modal
3. Focus Mode
4. Session Wrap-up / TIL

## Layout rule
The campus scene owns the majority of the viewport. Productivity controls occupy deliberately quiet negative space and stay in DOM/UI layers rather than being baked into art.

## MVP exclusions
No rooms, friends, Discord, chat, avatars, XP, progression, unlockables, multiple campus scenes, calendar integrations, AI, flashcards, full Kanban, native app, or public profiles.

## Brand/identity rule
This is an **unofficial student-made product**. Do not use a modified UP seal or a modified transparent Oblation icon as product branding. The scene may be campus-inspired and include distant architectural/monument cues, but the app uses its own name and identity.
